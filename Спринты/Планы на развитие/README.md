## Как добавить новое предложение

1. Добавить пункт в [008](008_unified_plan/008_unified_plan.md) в формате остальных: свой код в блоке (следующий
   свободный, например B16 или D9), этап, факты, решение, где в коде, как проверяем, зависимости.
2. Добавить строку в сводную таблицу раздела 1 и место в порядке работ раздела 2.
3. Если пункт меняет уже принятое решение — пометить △ и записать в приложение 6.2 с датой и согласием владельца.
4. Объёмные материалы (замеры, эталоны) — отдельным файлом в папке `008_unified_plan/` со ссылкой из пункта.
