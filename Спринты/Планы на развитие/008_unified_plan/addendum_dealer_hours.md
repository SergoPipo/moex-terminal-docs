## Что проверяется

| № | Вопрос | На что влияет |
|---|---|---|
| 1 | Принимает ли T-Invest API заявки в часы дилера (выходные 02:00–10:00 и 19:00–23:50 МСК) | A5, C1 — можно ли включать признак «стопы у дилера» |
| 2 | Спред дилерского стакана против биржевого (SBER, GAZP, LKOH, AFLT) | порог спреда для того же признака |
| 3 | Помечает ли поток свечей источник (`candle_source_type`) — с `INCLUDE_WEEKEND` и без указания источника | A1 — одна подписка с раскладкой по источнику или две |

Снимки: суббота 24.10 15:00 МСК (биржа, для сравнения), суббота 20:30, воскресенье 08:30 и 21:00 (дилер); база будней —
20.10.2026. Только чтение данных: заявки не отправлялись, вывод по вопросу 1 делается по флагам API.

## 1. Что показала проверка

Источник — проект исследования (`Tradingview/docs/14-execution-plan.md`, раздел A5, «Результаты проверки дилера
24–25.10.2026»; данные — `Tradingview/tools/out/dealer_check_2026102*_MSK.json`). Каждый запуск — 60 с на фазу,
4 бумаги; фаза A — подписка `CANDLE_SOURCE_INCLUDE_WEEKEND`, фаза B — без указания источника (как подписывается Moex).

**Биржевой сессии в эти выходные не было** ни в субботу, ни в воскресенье (ISS: у SBER нет 1h-свечей за 24–25.10,
последняя сделка 23.10 23:49:57), поэтому снимок 24.10 15:00, задуманный как биржевой, снял дилера.

| Снимок, МСК | Площадка | Статус торгов | Флаги заявок API (API / лимитные / рыночные) | Спред, б.п., медиана: SBER / GAZP / LKOH / AFLT | `candle_source_type` в потоке (фаза A / B) |
|---|---|---|---|---|---|
| 20.10 11:22 (будни, база) | биржа | `NORMAL_TRADING` | True / True / True | биржа: 0,3 / 0,9 / 0,8 / 2,8 | `EXCHANGE` 138 / 63 |
| 24.10 15:01 | дилер (биржи нет) | `DEALER_NORMAL_TRADING` | True / True / True | 8,9 / 4,3 / 8,1 / 13,9 | `DEALER_WEEKEND` 18 / 11 |
| 24.10 20:31 | дилер | `DEALER_NORMAL_TRADING` | True / True / True | 8,9 / 8,7 / 7,3 / 7,0 | `DEALER_WEEKEND` 7 / 21 |
| 25.10 08:31 | дилер | `DEALER_NORMAL_TRADING` | True / True / True | 0,3 / 3,5 / 0,8 / 2,8 | `DEALER_WEEKEND` 10 / 14 |
| 25.10 21:01 | дилер | `DEALER_NORMAL_TRADING` | True / True / True | 7,9 / 8,7 / 9,7 / 16,7 | `DEALER_WEEKEND` 6 / 4 |

- **(1) Заявки в часы дилера — по флагам разрешены** во всех 4 выходных снимках (`api_trade_available_flag`,
  `limit_order_available_flag`, `market_order_available_flag`, `weekend_flag` — True). Реальная заявка не
  отправлялась: исполнение у дилера через API не проверено.
- **(2) Спред.** Днём и вечером спред дилера в 2,5–30 раз шире биржевого в будни; утром в воскресенье у SBER, LKOH,
  AFLT — 1 шаг цены. Максимум за все снимки — 16,7 б.п. (AFLT). Выход рыночной заявкой — около половины спреда:
  2–8 б.п. Глубина 10 уровней у дилера в 2–17 раз меньше биржевой, но больше обычной частной заявки. Биржевого стакана
  в выходные нет (событий 0).
- **(3) Источник свечей.** В часы дилера все свечи — `CANDLE_SOURCE_DEALER_WEEKEND`, и с `INCLUDE_WEEKEND` (41 из 41), и
  без указания источника (50 из 50): поле источника в потоке заполняется. Одной подписки с раскладкой по источнику
  достаточно. Не проверено: выходной, в который работают и биржа (10:00–19:00), и дилер.
- **Расписание.** Расписание на 25.10 поменялось в тот же день: утром на 10:00–19:00 стояла биржевая сессия, к вечеру —
  дилер весь день 02:00–23:50, биржевых сделок не было. В выходной без биржевой сессии дилер работает весь день.

## 2. Принятые правила

| Пункт | Правило | Статус |
|---|---|---|
| A1 — режим потоковой подписки | **одна подписка** `CANDLE_SOURCE_INCLUDE_WEEKEND` с раскладкой по `candle_source_type`: биржевые свечи — в основной ряд, дилерские — в `ohlcv_dealer` и в свой канал; режим «две подписки» не нужен | принято 2026-10-26 |
| A5, C1 — признак «стопы у дилера» | делается полностью, **по умолчанию выключен**; включать **можно** — включает владелец сам, после одной своей ручной заявки на 1 лот в часы дилера (ответ брокера и цена исполнения). Стоп в часы дилера проверяется **по дилерским ценам** (свечи `DEALER_WEEKEND` или дилерский стакан), а не по последней биржевой цене | принято 2026-10-26 |
| A5, C1 — порог спреда для признака | **20 б.п.**: перед заявкой — текущий дилерский стакан; спред ≤ 20 б.п. — рыночная заявка; шире — автоматический выход не отправляется, уведомление (бумага, цена, спред), проверка повторяется каждую минуту; ручное закрытие доступно всегда | принято 2026-10-26 |
| A5, C1 — проверка перед заявкой в часы дилера | статус `SECURITY_TRADING_STATUS_DEALER_NORMAL_TRADING` и флаги `api_trade_available_flag`, `market_order_available_flag`; иначе заявки нет, уведомление | принято 2026-10-26 |
| A5 — как определять часы дилера в выходные | по текущему статусу торгов бумаги (`GetTradingStatus`) или по расписанию, перечитанному в тот же день перед окном, — не по расписанию накануне; в выходной без биржевой сессии часы 10:00–19:00 — тоже часы дилера | принято 2026-10-26 |
